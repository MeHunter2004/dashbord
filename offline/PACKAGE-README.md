# داشبورد پایش درخواست‌ها — اجرای آفلاین

این بسته به اینترنت، Python، Node.js یا npm نیاز ندارد.

## راه‌اندازی

1. محتویات ZIP را کامل در یک پوشه روی رایانه استخراج کنید.
2. فایل `پایش کل درخواست ها MASTER.xlsx` را در این مسیر قرار دهید:

   ```text
   backend\data\پایش کل درخواست ها MASTER.xlsx
   ```

3. روی `start-dashboard.bat` دابل‌کلیک کنید.
4. آدرس نمایش‌داده‌شده را در مرورگر باز کنید:
   - همان رایانه: `http://127.0.0.1:8000`
   - تلفن در همان Wi-Fi مورداعتماد: `http://IP-نمایش‌داده‌شده:8000`

اگر Windows Firewall درخواست دسترسی داد، فقط برای شبکه Private و مورداعتماد آن را تأیید کنید.

برای توقف برنامه، پنجره سیاه Dashboard را باز کرده و `Ctrl + C` را بزنید.

## به‌روزرسانی داده‌ها

فایل Excel را با همان نام در پوشه `backend\data` جایگزین کنید و در داشبورد دکمه `بروزرسانی داده‌ها` را بزنید.
