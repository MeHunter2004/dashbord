# بسته آفلاین داشبورد

این پوشه خروجی قابل تحویل به کارفرما را تولید می‌کند. خروجی در `offline/package/EDR-Dashboard-Offline/` ساخته می‌شود و شامل Python runtime، وابستگی‌های بک‌اند، رابط build‌شده و لانچر دابل‌کلیک است.

فایل Excel عمداً در Git و بسته خروجی قرار نمی‌گیرد. پیش از تحویل، فایل `پایش کل درخواست ها MASTER.xlsx` را در پوشه `data/` خروجی کپی کنید.

## ساخت بسته

روی سیستم توسعه، پس از نصب وابستگی‌ها، این فایل را اجرا کنید:

```bat
offline\build-offline.bat
```

این مرحله از Python و وابستگی‌های نصب‌شده روی سیستم توسعه کپی می‌گیرد و به اینترنت نیاز ندارد. سیستم کارفرما برای اجرای بسته به Python، Node.js، npm یا اینترنت نیاز ندارد.
